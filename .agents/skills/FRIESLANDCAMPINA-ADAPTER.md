# FrieslandCampina adapter for the document skills

This file is the per-user adapter for the four Anthropic document
skills in this folder. It is kept separate from the copied SKILL.md
files, so the core stays generic and this adapter can change without
touching the core.

Read this file together with the skill that matches the task, whenever
the document is a FrieslandCampina work document.

## Word reports

- Company Word reports come from DocSys Online at
  frieslandcampina.docsys.online, not from a local template file.
- All text is Verdana size 9. Layout is compulsory. Do not change the
  font size, type, colour, or logo.
- Workflow: log on, New Document, pick the type, fill the fields,
  resolve warnings, Preview, Finish, download as docx, then type the
  content in Word.

## PowerPoint reports

- Start from the FrieslandCampina 2020 template
  `Presentation_template.pptx`, 16:9, canvas 10 by 5.625 inches.
- Font Verdana, theme blue accent 0094D9, footer
  "Draft | Internal use only | Confidential" with slide numbers.
- The template file is a 46-slide example deck, not blank. Start from
  its layouts and masters and replace the example content and images.
- For infant nutrition (IFT, Friso, until 3 years and MUM), use the
  logo version WITHOUT the "Nourishing by Nature" tagline. Never use
  that tagline for infant nutrition promotion.

## Spreadsheets

- Follow the user's spec literally: exact tab names, exact column
  headers, and the exact formula spelled out.
- Write formulas in the cells, never hardcoded results.
- Use tab-separated tables when the result must paste cleanly into
  Excel.
